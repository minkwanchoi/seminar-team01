## 2. 문장으로만 막고 있는 항목

설정 파일을 읽어 확인했습니다(2026-11-26). 프로젝트에는 `.claude/settings.json`이 없고, 사용자 전역 설정에도 금지(`deny`)·확인(`ask`) 규칙과 훅이 없습니다. 그래서 아래는 모두 지시문과 에이전트의 판단에만 기대고 있습니다.

- 팀 저장소 push 금지. 실제로 2026-10-25에 실수로 `git push origin`을 한 적이 있음(에이전트 메모리 기록)
- 원자료·결과 파일 손수정 금지
- 비공개 자료 커밋 금지(`.gitignore`는 `-f`로 넘을 수 있음)

권한으로 옮길 수 있는 방법(설정 변경이라 적용하지 않았고, 사용자가 정할 일):

- 프로젝트 `.claude/settings.json`에 `Ref/`, `*.pdf`, `data/cwe/*/overlap_*.csv` 편집 금지와 `git push origin` 금지 규칙을 넣기
- 커밋 전에 검산 스크립트를 돌리는 훅
- `origin`의 push 주소를 막아 두기(`git remote set-url --push origin no_push`)
