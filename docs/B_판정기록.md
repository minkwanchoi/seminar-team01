## 2. B6: 판정 규칙

### 2.1 경과 (2026-11-21)

이 절의 초안(R1~R6)과 B6 본 실행·판정은 같은 날 따로 진행되어, 본 실행(`run_tools.py --all --name all-20261121`)과 판정 코드(`static-analysis/judge.py`)를 만들 때 초안을 보지 못했습니다. 그래서 실제 판정은 아래 2.2의 규칙(J7~J15)으로 했습니다.

- **결과 보기 전에 코드로 정함:** J7~J12, J14, J15. 본 실행이 도는 동안 시험 실행 케이스 3개(CWE-416·476·78)의 출력만 보고 정했습니다. 판정 코드를 1,285개 케이스 전체 결과에 처음 돌리기 전에 모두 정했고, 전체 결과를 본 뒤 바꾼 규칙은 없습니다.
- **다만 이 문서에 미리 적지는 않았습니다.** 그래서 기록 자체는 사후 기록입니다.
- **결과 본 뒤 정함:** J13(대표 수치를 '같은 번호' 기준으로 함, 아래 변경 이력)과 오탐 표본의 유형 분류. 유형 분류는 결과를 읽어야 할 수 있는 일이라 처음부터 사후 판단입니다.
