## 4. 작업 흐름과 규칙

- **원문 대조 먼저:** AI가 적은 번호·쪽수는 원문 PDF의 그 쪽을 열어 확인한 뒤에만 `status`를 `확인`으로 바꿉니다.
- **검수는 다른 경로로:** 같은 AI에게 다시 묻는 것은 독립 확인으로 치지 않습니다. 다른 자료(진단가이드, 기술노트, MITRE CSV), 다른 계산 경로(`verify_overlap.py`), 다른 사람(팀원 A)으로 확인합니다.
- **멈추는 장치:** `check_inputs.py`와 `verify_overlap.py`가 기준값과 다르면 종료 코드 1로 멈춥니다.
- **공개하지 않는 것:** 원문 PDF, 강의자료, 보고서 초안, 설명영상 대본은 `.gitignore`나 `local/`로 저장소 밖에 둡니다.
