# 손으로 센 예시 (검산용)

`analysis/overlap.py`가 겹침을 맞게 세는지 사람이 손으로 확인할 수 있게 만든 작은 목록입니다. 실제 제도 자료가 아니며 번호도 실제 CWE와 관계없습니다.

| 파일 | 행 | 펼친 번호 집합 | 일부러 넣은 경우 |
|---|---|---|---|
| `list_a.csv` | `1;2`, `3`, `3;4` | A = {1, 2, 3, 4} | 1:N 매핑, 다른 행에 같은 번호(3)가 다시 나옴 → 한 번만 셈 |
| `list_b.csv` | `3;4`, `5` | B = {3, 4, 5} | |
| `list_c.csv` | `4`, `6`, (빈칸) | C = {4, 6} | 번호가 빈 행 → 건너뜀 |

## 손으로 센 결과 (`expected.csv`)

Jaccard = 교집합 크기 ÷ 합집합 크기.

| 쌍 | 교집합 | 합집합 | Jaccard | 한쪽에만 |
|---|---|---|---|---|
| A, B | {3, 4} → 2 | {1, 2, 3, 4, 5} → 5 | 2/5 = 0.4 | A 2개(1, 2), B 1개(5) |
| A, C | {4} → 1 | {1, 2, 3, 4, 6} → 5 | 1/5 = 0.2 | A 3개, C 1개 |
| B, C | {4} → 1 | {3, 4, 5, 6} → 4 | 1/4 = 0.25 | B 2개, C 1개 |

- 세 목록 모두에 공통: {4} → 1개
- 다른 목록에 없는 고유 번호: A 2개(1, 2), B 1개(5), C 1개(6)

## 확인하는 방법

```bash
.venv/Scripts/python analysis/verify_overlap.py
```

첫 단계에서 이 예시를 `overlap.py`의 함수로 계산해 위 표와 한 칸씩 맞춰 봅니다. 하나라도 다르면 실제 자료 검산으로 넘어가지 않고 멈춥니다.
